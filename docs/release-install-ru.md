# DOS2DLSS 0.6.1-preview.1 — установка

Экспериментальный мод для Divinity: Original Sin 2 **Definitive Edition**, Windows x64, версия игры **3.6.117.3735**, видеокарта NVIDIA RTX с поддержкой DLSS. Это предварительный релиз, а не стабильная версия.

## Установка

1. Закройте игру. Через RHI установите ReShade с поддержкой аддонов для DX11, 64-bit, в `DefEd\bin`.
2. Распакуйте весь архив в отдельную папку. Не запускайте установщик внутри ZIP.
3. Нужен [PowerShell 7](https://github.com/PowerShell/PowerShell/releases). Для стандартного пути `D:\SteamLibrary\steamapps\common\Divinity Original Sin 2` запустите `Install.cmd`.
4. Для другого пути откройте PowerShell 7 в распакованной папке и выполните:

```powershell
.\scripts\install.ps1 -GameRoot 'E:\SteamLibrary\steamapps\common\Divinity Original Sin 2'
```

5. Запустите игру через Steam/RHI. Откройте панель ReShade назначенной клавишей (в тестовой установке F11), вкладка **DOS2 DLSS**. Для первой проверки выберите **DLAA**.

Установщик проверяет версию EXE, сохраняет оригинальный Bink и устанавливает NativeModLoader, нативную DLL и аддон ReShade. Поставляемая DLL DLSS копируется только если её ещё нет: установленная RHI версия не перезаписывается. Существующие настройки DOS2DLSS сохраняются.

## Дополнительный DLSS5 NR

Для обычного DLSS/DLAA RenoDX и Bridge не требуются. Для NR сначала установите соответствующие RenoDX DLSS5 NR и runtime через RHI, затем запустите наш установщик последним: он установит доработанный Bridge. Feeder не нужен и отключается установщиком.

Доработанный Bridge читает настройку NR: при выключенном NR обходит зеркало DX12, при включённом NR использует его и пропускает дублирующий DLSS-проход. Для него нужны `stage=3`, `skip_game=1`, `synth=0`; установщик задаёт эти значения. Сам NR и передача данных требуют ресурсов GPU. Если RHI обновит Bridge, повторите установку нашего пакета.

ReShade, RenoDX и библиотеки NR в архив не входят. Проверка NR проводилась с установленным runtime 310.8.x; совместимость с любыми будущими версиями не гарантируется.

## Известные проблемы

- В Quality/Balanced/Performance обводки интерактивных объектов могут смещаться и оставлять белые следы; возле полоски HP возможны фрагменты UI и миникарты. Исправление ещё не готово. Пользователь не наблюдал эти дефекты в DLAA.
- Полноценные векторы движения персонажей пока отсутствуют; возможны шлейфы и нестабильность листвы.
- Предыдущие исправления мерцания/вылетов DLAA проверены ограниченно; полная стабильность не подтверждена.
- Обход Bridge при NR off и работа NR on проверены отдельными запусками в меню. Переключение NR на лету и прирост FPS в сохранении ещё не подтверждены.

## Удаление

Закройте игру и выполните в PowerShell 7:

```powershell
.\scripts\uninstall.ps1 -GameRoot 'D:\SteamLibrary\steamapps\common\Divinity Original Sin 2'
```

Общая библиотека `nvngx_dlss.dll` и дополнительный Bridge могут остаться; для восстановления исходного Bridge используйте RHI. Не удаляйте библиотеки, необходимые другим модам.
